# Privlychat

## Description / 소개
A web-based chat application designed for real-time communication with fundamental encryption.
실시간 통신과 기본 암호화를 구현한 웹 기반 채팅 애플리케이션입니다.

## Features / 주요 기능
- **Real-time Messaging**: Fast and seamless communication utilizing WebSockets.
- **Message Encryption**: Secure data transmission applied through the npm `crypto_box` library.
- **실시간 메시징**: 웹소켓(WebSockets)을 활용한 빠르고 끊김 없는 통신.
- **메시지 암호화**: npm `crypto_box` 라이브러리를 적용한 안전한 데이터 전송.

## Tech Stack / 기술 스택
- **Environment**: Node.js
- **Network**: WebSockets
- **Security**: npm `crypto_box`

## Getting Started / 시작하기

### Prerequisites / 사전 요구 사항
- Node.js (npm)

### Installation & Run / 설치 및 실행

```bash
# Clone the repository
git clone [https://github.com/0x5357/Privlychat.git](https://github.com/0x5357/Privlychat.git)

# Navigate to the project directory
cd Privlychat

# Install dependencies
npm install

# Start the application
npm start
